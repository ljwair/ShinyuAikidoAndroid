# Integrated 3D Aikido Trainer

This build merges the Shinyu Aikido Android app with the Aikidoka Gesture 3D v3.9 movement engine.

## Where it appears

A new **Trainer** tab is added to the main bottom navigation between Schedule and Explore.

## Trainer controls

- Okuri + / Okuri -
- Ayumi + / Ayumi -
- Tsugi + / Tsugi -
- Tenkai
- Tenkan
- Irimi tenkan
- Reset stance

The 3D dojo still accepts the gesture grammar from the standalone trainer, but the buttons are the primary test controls.

## App identity

The package remains `org.shinyuembody.aikido`, so this project updates the existing Shinyu Aikido app rather than installing a separate trainer app.

Version: 1.1.0 (versionCode 2)
